NEXUS - INSTRUCOES COMPLETAS
============================

Este projeto permite:
- Enviar uma planilha Excel para analise financeira.
- Ler todas as abas do arquivo.
- Identificar maiores e menores contas.
- Calcular total, media, mediana e valores fora do padrao.
- Receber leituras de energia enviadas por um ESP32.
- Exibir consumo e custo em texto, tabela e graficos de pizza.


1. ESTRUTURA PRINCIPAL
======================

app.py
    Servidor Flask e APIs do sistema.

templates/index.html
    Interface web com as abas Resumo financeiro e Energia ESP32.

requirements.txt
    Bibliotecas Python necessarias.

essp32_energia/esp32_energia.ino
    Programa de exemplo para o ESP32.

dados_graos.xlsx
    Planilha de exemplo local.

=======================

https://www.python.org/downloads/windows/

Durante a instalacao, marque:

Depois de instalar, feche e abra o terminal novamente.

Confirme a instalacao:

    python -m pip --version

=================

Na pasta do projeto, execute:

O terminal precisa permanecer aberto enquanto o site estiver sendo usado.

Para parar o servidor, pressione Ctrl+C no terminal.


5. USAR A ABA FINANCEIRA
========================

1. Abra http://localhost:5000.
2. Na aba Resumo financeiro, escolha um arquivo .xlsx ou .xls.
3. Tambem e possivel arrastar o arquivo para a area de upload.
4. O sistema analisa todas as abas.
5. A coluna de valores e identificada automaticamente por nomes como:
   valor, preco, custo, total, despesa ou gasto.
6. O resultado mostra:
   - total analisado;
   - quantidade de contas;
   - valor medio;
   - contas acima da media;
   - maior conta;
   - menor conta;
   - grupos por categoria, tipo ou fornecedor;
   - contas fora do padrao estatistico.


6. COMO FUNCIONA O FORA DO PADRAO
==================================

O sistema usa o intervalo interquartil, conhecido como IQR.

Uma conta e marcada como fora do padrao quando fica acima ou abaixo dos limites:

    limite inferior = Q1 - 1,5 x IQR
    limite superior = Q3 + 1,5 x IQR

Q1 e Q3 sao os quartis dos valores analisados.

Isso e uma regra estatistica automatica, nao uma conclusao contabil.
Sempre confira os registros originais antes de tomar uma decisao.


7. CONFIGURAR O ESP32
=====================

O programa de exemplo esta em:

    esp32_energia\esp32_energia.ino

Abra o arquivo na Arduino IDE ou no PlatformIO.

No inicio do arquivo, altere:

    const char* WIFI_SSID = "SUA_REDE_WIFI";
    const char* WIFI_SENHA = "SUA_SENHA_WIFI";
    const char* API_URL = "http://192.168.1.100:5000/api/energia/leitura";
    const char* DISPOSITIVO = "Quadro principal";

Exemplo:

    const char* WIFI_SSID = "MinhaRede";
    const char* WIFI_SENHA = "minha-senha";
    const char* API_URL = "http://192.168.1.100:5000/api/energia/leitura";
    const char* DISPOSITIVO = "Motor 01";

IMPORTANTE:
- Nao use localhost no API_URL.
- O ESP32 precisa usar o IP do computador na rede local.
- O computador e o ESP32 precisam estar na mesma rede Wi-Fi.
- O servidor Flask precisa estar rodando.
- O firewall do Windows pode precisar liberar a porta 5000.


8. DESCOBRIR O IP DO COMPUTADOR
===============================

No PowerShell, execute:

    ipconfig

Procure o endereco IPv4 do adaptador Wi-Fi, por exemplo:

    IPv4 Address . . . . . . . . . . : 192.168.1.100

Use esse endereco no API_URL do ESP32:

    http://192.168.1.100:5000/api/energia/leitura


9. SENSOR E LIGACAO ELETRICA
============================

O exemplo usa dois pinos ADC do ESP32:

    PINO_TENSAO   = 34
    PINO_CORRENTE = 35

O codigo considera:

    tensao da rede = 220 V
    tarifa = R$ 0,95 por kWh

Esses valores podem ser alterados no arquivo .ino:

    const float TENSAO_REDE_V = 220.0;
    const float TARIFA_KWH = 0.95;

ATENCAO:
- O codigo e uma base generica para sensor de corrente analogico.
- A constante SENSIBILIDADE_CORRENTE precisa ser ajustada ao modelo do sensor.
- Sensores SCT-013, ACS712, PZEM-004T e outros usam formas diferentes de leitura.
- Para medir tensao da rede, use um modulo apropriado e isolado.
- Nunca conecte a tensao da rede diretamente ao pino do ESP32.
- Trabalhar com 127 V ou 220 V pode causar choque, incendio ou morte.
- Use um profissional habilitado para instalar sensores em quadro eletrico.

Se for usado um PZEM-004T, o codigo devera ser adaptado para a biblioteca e comunicacao serial do PZEM. Nao basta trocar apenas o numero do pino.


10. CALIBRACAO DA CORRENTE
===========================

No arquivo .ino existe:

    const float SENSIBILIDADE_CORRENTE = 0.100;
    const float OFFSET_CORRENTE_A = 0.0;

Esses valores sao exemplos.

Para calibrar:
1. Confira a documentacao do sensor.
2. Use uma carga conhecida.
3. Compare a corrente mostrada pelo ESP32 com um instrumento confiavel.
4. Ajuste SENSIBILIDADE_CORRENTE e OFFSET_CORRENTE_A.
5. Repita o teste antes de confiar nos custos exibidos.


11. FUNCIONAMENTO DA MEDICAO
============================

A cada 60 segundos, o ESP32:

1. Mede a corrente.
2. Calcula potencia:

    potencia = tensao x corrente

3. Calcula a energia do intervalo:

    energia_kWh = potencia_W x tempo_em_horas / 1000

4. Calcula o custo:

    custo = energia_kWh x tarifa

5. Envia a leitura para o Flask.

O intervalo pode ser alterado no .ino:

    const unsigned long INTERVALO_MS = 60000;


12. FORMATO ENVIADO PELO ESP32
==============================

O ESP32 envia um JSON semelhante a este:

{
  "dispositivo": "Motor 01",
  "energia_kwh": 0.125,
  "custo_brl": 0.12,
  "potencia_w": 750.0,
  "tensao_v": 220.0,
  "corrente_a": 3.41
}

A API tambem aceita timestamp. Se ele nao for enviado, o servidor cria automaticamente.


13. TESTAR A API SEM ESP32
==========================

Com o servidor rodando, abra outro PowerShell e execute:

    $body = @{
        dispositivo = "Teste"
        energia_kwh = 1.25
        custo_brl = 1.19
        potencia_w = 750
        tensao_v = 220
        corrente_a = 3.41
    } | ConvertTo-Json

    Invoke-RestMethod `
        -Uri http://localhost:5000/api/energia/leitura `
        -Method Post `
        -ContentType "application/json" `
        -Body $body

Para consultar as leituras:

    Invoke-RestMethod http://localhost:5000/api/energia

Depois abra a aba Energia ESP32 no site e clique em Atualizar.


14. ENDPOINTS DISPONIVEIS
=========================

GET /
    Abre o site.

POST /api/analisar
    Recebe um arquivo Excel no campo multipart chamado arquivo.

GET /api/energia
    Retorna resumo, leituras e totais por dispositivo.

POST /api/energia/leitura
    Recebe uma leitura JSON do ESP32.

Exemplo de resposta de sucesso:

    HTTP 201
    {"mensagem":"Leitura recebida.","leitura":{...}}


15. LIMITACAO ATUAL DOS DADOS DE ENERGIA
=========================================

As ultimas 500 leituras ficam armazenadas somente na memoria do processo Flask.

Isso significa que os dados sao perdidos quando:
- o servidor e reiniciado;
- o computador e desligado;
- o processo Flask e encerrado.

Para uso permanente, o proximo passo recomendado e salvar as leituras em SQLite ou PostgreSQL.


16. PROBLEMAS COMUNS
====================

Site nao abre:
- Confira se python app.py esta rodando.
- Tente http://127.0.0.1:5000.
- Verifique se outra aplicacao ja usa a porta 5000.

ESP32 nao envia:
- Confira SSID e senha.
- Confirme que o IP no API_URL e o IP do computador.
- Confirme que computador e ESP32 estao na mesma rede.
- Verifique o Monitor Serial em 115200 baud.
- Teste primeiro a API pelo PowerShell.
- Libere a porta 5000 no firewall, se necessario.

Valores incorretos:
- Confira a tensao configurada.
- Confira a tarifa por kWh.
- Calibre a sensibilidade do sensor.
- Confirme o tipo exato de sensor usado.
